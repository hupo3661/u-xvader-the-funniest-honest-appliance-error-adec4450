One line, at most 200 characters: the funniest honest error message an appliance could show. A dishwasher reports the dishes came out still dirty because the bowls were loaded upside down — so it spent the cycle rinsing the ceiling. `main.py` writes it to `/output/entry.txt` — deterministic, no network, no input.

## Run it

```sh
python3 main.py
```
